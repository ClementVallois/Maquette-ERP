# Décisions d'architecture (ADR)

Un ADR par arbitrage structurant, écrit **au moment** de l'arbitrage. Format : `NNNN-titre-en-kebab-case.md`, à partir de `0000-template.md`.

Chaque ADR doit répondre à trois questions qu'un relecteur posera de toute façon : **quelle option a été écartée**, **pourquoi elle perd dans ce contexte précis**, et **à quel seuil on changerait d'avis**.
